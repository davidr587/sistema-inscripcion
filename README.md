Este repositorio contiene el código fuente de un Sistema de Inscripción Full-Stack desarrollado desde cero (PHP, MySQL y frontend optimizado con Gulp) en etapas anteriores de mi carrera.

Actualmente, mantengo este código público como evidencia de mis fundamentos integrales en el ciclo de vida del software. Haber construido tanto la lógica de negocio y las bases de datos, como las interfaces con las que interactúa el usuario final, ha sido el pilar de mi evolución hacia la Ciberseguridad y la Coordinación de Sistemas.

Hoy en día, evaluaría este código implementando pruebas de seguridad estática (SAST). El objetivo sería mitigar riesgos en la autenticación (login.php), blindar las consultas a la base de datos y auditar las vistas del frontend para prevenir vulnerabilidades de inyección y manipulación del lado del cliente.
