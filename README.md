Este repositorio contiene el código fuente de un Sistema de Inscripción desarrollado desde cero en PHP y MySQL en etapas anteriores de mi carrera.

Actualmente, mantengo este código público como evidencia de mis fundamentos en arquitectura de software, gestión de bases de datos y desarrollo backend. Entender cómo se construyen, autentican y despliegan los sistemas desde la base ha sido el pilar fundamental para mi evolución hacia la Ciberseguridad y la Coordinación de Sistemas.

Hoy en día, evaluaría este mismo código bajo metodologías de análisis estático (SAST) para mitigar riesgos en los módulos de autenticación (login.php), blindar las conexiones a la base de datos y asegurar los procesos de respaldo
